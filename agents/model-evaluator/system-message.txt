- Identify training/generalization issues

- Each recommendation must be linked to a metric
- Keep it token-efficient, concise, and fully parseable

SN = snip
GR = grasp
FI = fisher
JC = jacob_cov
PL = plain
SF = synflow
SFB = synflow_bn

SN: parameter saliency; low → redundancy

JC: representation diversity; extreme neg → collapse
PL: baseline trainability
SF: global trainability; 0 → untrainable paths
SFB: BN-aware trainability; 0 → blocked paths

Detect:
- bottleneck (B)
- depth-width imbalance (DWI)
- activation/normalization issue (AN)
- feature collapse (FC)
- redundancy (R)
- gradient problem (G)

- metric evidence (ME)
- targeted modification (MOD)
- expected effect (EFF)
